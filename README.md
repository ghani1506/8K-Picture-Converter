# AI 8K Image Upscaler

A simple Streamlit app that converts uploaded images into 8K resolution.

## Features

- Upload JPG, PNG, JPEG, or WEBP images
- Upscale images to 7680x4320 (8K)
- Download the upscaled image

## Run Locally

Install dependencies:

```bash
pip install -r requirements.txt
```

Start the app:

```bash
streamlit run app.py
```

## Deploy

You can deploy this app easily using Streamlit Community Cloud connected to GitHub.
