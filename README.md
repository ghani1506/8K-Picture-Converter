# AI HD & 8K Upscaler

Improves image quality and increases resolution to HD / 4K / 8K.

## Features
- Sharpen image
- Increase clarity
- Enhance colors
- Upscale to 2K / 4K / 8K
- Download HD output

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy on Streamlit Cloud
1. Upload to GitHub
2. Connect GitHub to Streamlit
3. Deploy app.py
